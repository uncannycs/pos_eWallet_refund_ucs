Overview

This module enhances the Odoo Point of Sale by integrating eWallet balances directly into the POS screen and enabling secure eWallet refunds.

  • Seamlessly refund eWallet payments directly from the POS interface.
  • Instantly view the selected customer's available eWallet balance on the POS screen.
  • Prevent over-refunding with built-in validation checks that block refunds exceeding the current eWallet balance.

Screenshots

1. Install the Application

Begin by installing the eWallet Refund POS application from the Odoo apps menu.

2. Customer eWallet Balance

In the backend, you can see the customer's current eWallet balance (e.g., 10,000).

3. Select Customer in POS

In the Point of Sale interface, select the customer for the current transaction.

4. Balance Displayed on Screen

Once selected, the customer's available eWallet balance is clearly visible on the POS screen.

5. Pay Using eWallet

Proceed to the payment screen and choose the eWallet payment method to complete the purchase.

6. Balance Deducted

After a successful payment, the transaction amount is automatically deducted from the customer's eWallet balance.

7. Initiate a Refund

You can seamlessly process a refund for a previous order directly from the POS interface.

8. Process Refund via eWallet

When processing the refund, the system tracks the refund amount being credited back to or deducted from the eWallet.

9. Validation Check on Payment

When clicking the payment button, the module performs a validation check to ensure the refund amount doesn't exceed the available eWallet balance.

10. Refund Validation Error

If the attempted refund exceeds the customer's eWallet balance, an error message is displayed to prevent the over-refund.

11. Valid Refund Processing

If the requested refund amount is valid (less than or equal to the eWallet balance), the transaction proceeds normally.

12. Refund Successful

The refund is processed successfully, and the system generates the corresponding receipt.

13. eWallet Balance Updated

Finally, the customer's eWallet balance is automatically updated in the backend to reflect the refunded amount.
